# chrysalyst
Chrysalyst verwandelt vage Produktideen durch ein geführtes Interview in klare, entwicklungsreife Spezifikationen. Mit einer lokalen, kleinen LLM. Statt zu raten, stellt die App gezielte Rückfragen und destilliert deine Antworten Schritt für Schritt zu einer strukturierten, widerspruchsfreien Spec.
